# ARK Learning Lab

Public site for **ARK Learning Lab**, with three pathways: **Core Academy**, **UnSchool**, and **LIBERVERSE Learning Lab**. The programme includes a proposed Science & Civics Pack, practical skill-card previews, a draft online ARK River Pilot (the Danube is one of five featured rivers), a free portfolio builder, the Proof Kit prototype and a private learner-agency reflection tool.

## Status and philosophy

ARK Learning Lab is a draft enrichment programme for ages 6–18, not an accredited school, qualification or official Liberland government institution. Enrolment, payments, mentor services and ARK Village activities are not open. Draft pricing is not an offer for sale. Complete curriculum materials, approved safeguarding arrangements and local legal review are required before enrolment or activities with minors. Learners never receive crypto wallets, tokens, payments or Liberland Merits.

Learners can choose inquiry questions, roles and evidence formats. Liberland is an optional civics case study, not a political belief test. The official Liberland Constitution page says the Constitution is being drafted; current text, proposals, claims and design choices are taught as distinct categories. The learner-agency reflection prompts are not a diagnostic or validated assessment and do not save responses.

## Publishing

The live site is served from the `main` branch at GitHub Pages. The `gh-pages` branch is a partial legacy copy and is not the deployment source; verify the Pages setting before removing it. The public CDN may cache a recent commit for several minutes. To check a fresh deploy, add a query string to a page URL.

The intended custom domain, `arklearninglab.com`, currently uses GoDaddy forwarding to this GitHub repository rather than the site. Point its DNS to GitHub Pages first, then set the custom domain in the Pages settings. Until then, keep `https://thefutureofwork.github.io/ARKlearninglab/` as the canonical address.
