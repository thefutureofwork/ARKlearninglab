# Liberland Academy

Public website for **Liberland Academy**, with its **UnSchool** and **LIBERVERSE Learning Lab** pathways, the **ARK Learning Lab** six-week pilot and the **Liberland Science & Civics Pack**.

## What's here

- `index.html`: the whole site, static, no build step. Fonts load from Google Fonts. Icons are inline SVG.

## Run it

Open `index.html` in a browser, or turn on GitHub Pages (Settings > Pages > Deploy from branch > `main` / root).

## Sections

1. Hero: "Free to choose. Bound to care." with the animated Danube
2. Pathways: Liberland Academy (core), UnSchool (self-directed), LIBERVERSE Learning Lab (online)
3. ARK Learning Lab six-week journey, with an age-band toggle (6-11 / 12-16)
4. Practical independence skills: ten skill cards with an age-band toggle (6-8 / 9-11 / 12-14 / 15-18) and a safety note
5. Three delivery streams: Un-screen pack, Online course, ARK on-site
6. Liberland Science & Civics Pack: 8 units + 6 audio stories with synopses
7. Packages: Family Pack, Pod License, Site License, ARK Intensive, compared row by row, plus add-ons (draft pricing)
8. Build-your-plan (Private ARK "build your own menu" pattern). Nothing is submitted or stored.
9. Status footer: enrichment, not accreditation; Liberland's Constitution is still being drafted.
